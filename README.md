# 🎵 POKÉ-SOUNDEX (포켓몬 애니메이션 OST 도감)

포켓몬스터 애니메이션(무인편 ~ W: 내 꿈은 포켓몬마스터)의 역대 주제가 **47곡**을 도감 형태로 탐색하고 감상할 수 있는 웹 기반 사운드 플레이어입니다.

🔗 **배포 페이지:** `https://yunhj14.github.io/PokeSong/`

---

## ✨ 주요 기능

* **포켓몬 도감 UI & 회전 LP 디스크**
  * 도감 컨셉의 2단 레이아웃(좌측 플레이어 / 우측 트랙 리스트)을 구현했습니다.
  * 곡 재생 시 중앙의 몬스터볼 LP 디스크가 회전하며, 곡 전환 시에도 프레임 크기가 흔들리지 않도록 고정 비율 레이아웃을 적용했습니다.
* **시리즈별 필터링 (재생 끊김 방지)**
  * `전체(47)`부터 `무인편`, `AG`, `DP`, `베스트위시`, `XY`, `XY&Z`, `썬&문`, `W`, `W:내 꿈은 포켓몬마스터`까지 총 10개 탭으로 곡을 분류해 볼 수 있습니다.
  * 감상 도중 다른 시리즈 탭으로 이동해도 현재 재생 중인 음악이 끊기지 않고 유지됩니다.
* **다양한 재생 컨트롤 (YouTube IFrame API 연동)**
  * 재생/일시정지, 이전/다음 곡, 프로그레스 바를 통한 구간 탐색을 지원합니다.
  * **셔플 재생(Shuffle):** 현재 선택된 시리즈 필터 목록 내에서 무작위 곡을 재생합니다.
  * **3단계 반복 재생(Repeat):** `반복 끄기` → `현재 리스트 전체 반복` → `현재 곡 1곡 무한반복` 순으로 전환됩니다.
* **모바일 반응형 지원**
  * 모바일 환경에서 헤더 렌즈 비율 왜곡을 방지하고, 컨트롤 버튼을 SVG 벡터 아이콘으로 구현해 기기별 이모티콘 깨짐 현상을 해결했습니다.

## 🛠️ 기술 스택

* **Frontend:** HTML5, CSS3 (Grid / Flexbox / Keyframe Animation), Vanilla JavaScript (ES6+)
* **API:** YouTube IFrame Player API
* **Deployment:** GitHub Pages

## 📂 디렉토리 구조

```text
├── index.html          # 메인 엔트리 포인트 및 플레이어 UI 마크업
├── css/
│   └── ost.css         # 도감 테마 스타일, 애니메이션 및 모바일 반응형 레이아웃

---

## 🔧 트러블슈팅 및 개선 사항

1. **정적 호스팅 환경에서의 음원 스트리밍 처리**
   * 초기 로컬 MP3 파일 방식에서 발생할 수 있는 저장소 용량 초과 및 저작권 문제를 해결하기 위해 **YouTube IFrame API** 기반 백그라운드 스트리밍 구조로 전환했습니다.
2. **GitHub Pages 배포 URL 단순화**
   * 정적 호스팅 루트 경로 접근성을 높이기 위해 기본 진입 파일명을 `ost.html`에서 `index.html`로 변경했습니다.
3. **모바일 크로스 브라우징 UI 보완**
   * 모바일 브라우저가 유니코드 기호(`▶`, `⏮`, `⏭`)를 컬러 이모티콘으로 자동 변환하는 문제를 해결하기 위해 모든 컨트롤 아이콘을 인라인 **SVG 벡터**로 교체했습니다.

## 🚀 로컬 실행 방법

YouTube IFrame API 보안 정책(`Origin` 검증)으로 인해 파일을 직접 더블클릭(`file://`)하면 재생이 차단되므로 로컬 웹 서버 환경에서 실행해야 합니다.

* **VS Code Live Server:** `index.html` 우클릭 후 `Open with Live Server` 실행
* **Python 내장 서버:**
  ```bash
  python -m http.server 8000
  # 브라우저에서 http://localhost:8000 접속
  ```
